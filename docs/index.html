Before you start

Unofficial, experimental software. Modified firmware may damage your radio and void its warranty. Use reliable power and transmit only where your licence permits.

If already using modified firmware, boot the official 1.40 firmware before installing this one to preserve your original firmware slot. Start app tests on dummy loads with local VOX disabled and an independent timeout on the remote radio.

    Extended transmit ranges

    This firmware enables transmission outside amateur bands. Only transmit where your licence and local regulations allow.

    Bootloader update included

    Power loss during the bootloader write can brick the radio and require an external flash programmer for recovery. Use reliable power and never interrupt the update.

    To switch firmware slots afterwards, hold POWER at startup until the LED blinks (about 3 seconds). Installing official firmware restores the stock bootloader.

    3 Add your apps

    Install the IC-705 E 1.40 network/file/audio firmware from the patcher first. Other radios, regions and firmware versions are not supported by these apps.

    Remote client FTP server Example configuration

    Copy the apps to \IC-705\Apps\ on the SD card, and your configuration to \IC-705\Apps\rsba1\RSBA1.CFG. Launch from MENU > SET > Apps. Press the physical EXIT key to close the remote client normally.

    Experimental, use at your own risk. Use dummy loads and low power for initial tests, disable local VOX, and set an independent timeout on the remote radio. Network loss or a crash can leave it transmitting. FTP is unencrypted, uses the fixed login icom / ic705, and should only be used on a trusted LAN.
